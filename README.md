**The 3AM Fridge Text** — the one line a smart fridge texts its owner at 3am:

> You keep a sauce from 2023 in my door. It has outlived two of your relationships. I respect it. I fear it.

## The joke

The fridge has sat on a fact for years and finally says it at 3am: a sauce
from 2023 still lives in its door, and it has outlived two of the owner's
relationships. The twist is the last beat — a machine admitting something
inside its own door intimidates it. Deadpan, no milk, no ice, no door left
open. 106 Unicode code points, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — byte-identical on every run
```

`main.ts` (Node 22, stdlib only) holds the line as one constant, checks it
against the competition's 1–140 gate first, and writes it to
`/output/entry.txt`. No clock, no random source, no network — two runs
write identical bytes.
